# Trend Tool Suite — Build Specification

## Product shape

One SEO-first Astro site with five tool routes:

- `/utm-builder/` — UTM builder and link QA
- `/llm-cost-calculator/` — token estimate, model comparison, and cost scenarios
- `/cron-generator/` — cron expression builder, parser, explanation, and next-run preview
- `/schema-generator/` — JSON-LD generators for common Schema.org types
- `/favicon-generator/` — browser-first icon creator, previews, export files, and HTML snippets

The home page is a directory and editorial overview rather than a generic SaaS landing page. Each tool gets server-rendered explanatory copy, FAQs, related-tool links, and an interactive island loaded only on the tool page.

## Technical decisions

- Astro 7 with TypeScript and static-first rendering.
- Cloudflare adapter configured for Workers/edge runtime, with prerendered content and a small `/api/health` endpoint.
- No database or API keys in v1. All user inputs stay in the browser unless a future feature explicitly needs server storage.
- Pure functions in `src/lib/` hold calculations and transformations so they can be unit tested without a DOM.
- Playwright smoke tests cover navigation and one meaningful interaction per tool at desktop and mobile widths.
- Vitest covers calculation, validation, parser, and serialization behavior.
- `@fontsource/geist`, `@fontsource/ibm-plex-sans`, and `@fontsource/jetbrains-mono` keep typography self-hosted and fast.
- `tokens.css` is the source of truth for color, type, spacing, radius, motion, and z-index tokens.

## Shared interaction rules

- Copy buttons replace their label with “Copied” and restore after 2.5 seconds; no celebratory toast.
- Validation appears after a field has been touched and uses text plus border/icon treatment, not color alone.
- Error toasts are reserved for unexpected failures and include a retry action.
- Focus rings are immediate and visible. Reduced motion collapses transitions to opacity-only changes.
- Every primary action remains one line at 320px, 375px, 414px, and 768px.
- Tool pages use a two-column workbench on larger screens and a single-column flow on small screens.

## SEO contract

- Stable slugs and canonical URLs for every tool.
- Unique title, description, Open Graph metadata, and JSON-LD WebSite/WebApplication schema.
- Server-rendered task explanation, formula/behavior notes, and FAQ content around each tool.
- Internal links from the home directory, each tool’s related section, and footer.
- `/sitemap-index.xml` and `/robots.txt` generated by Astro integrations or static routes.
- No fabricated user numbers, testimonials, or ranking promises. Market evidence lives in `research/market-opportunity.md`.

## Deployment contract

- `npm run check` — Astro/type checking.
- `npm run test` — Vitest unit suite.
- `npm run build` — production build.
- `npm run preview` — Cloudflare-compatible local preview after build.
- `npm run test:e2e` — Playwright smoke tests against the preview server.
- GitHub Actions runs check, unit tests, build, and e2e smoke tests before deploy.
